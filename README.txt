# Pick Your Death — Rhythm Monkeys

A browser rhythm game starter made for VS Code.

## Modes
- Easy — Max dont do it
- Medium — Home Made Kazoku (intentionally challenging)
- Hard — Galaxy Collapse (dense but beatable)

## Controls
A / S / K / L

VC CODE LIVE SERVER FOR ASHLEY 
**Live Server**, then right-click `index.html` and choose **Open with Live Server**.

Do not rename the files in `assets/music/` unless you also update `game.js`.

The supplied monkey image is used for the stage and transparent character cutouts are included in `assets/characters/`.
